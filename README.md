## Overview

Burger Shop is a modern and responsive restaurant website designed to showcase a burger brand, food menu, special offers, and contact details. The website focuses on a clean layout, attractive food presentation, and a smooth browsing experience for customers.

This project is suitable for a fast-food restaurant, burger shop, cafe, or food delivery landing page.

---

## Key Features

* Modern restaurant landing page
* Responsive design for mobile, tablet, and desktop
* Burger menu/product section
* Special offers section
* About section
* Contact section
* Clean navigation bar
* Attractive food-focused UI
* User-friendly layout

## Installation

Clone the repository:

```bash
git clone https://github.com/senuja1/burger-shop.git
```

Go to the project folder:

```bash
cd burger-shop
```

Open the project:

```bash
index.html
```

Or open it using Live Server in VS Code.
